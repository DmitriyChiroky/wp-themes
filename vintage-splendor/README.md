# Описание проекта

**Avintage Splendor** — это блог, предоставляющий пользователям доступ к платным статьям через премиум подписку, с уникальным контентом и удобным интерфейсом.

**Ссылка на сайт:** [www.avintagesplendor.com](http://www.avintagesplendor.com)

## Основные функции

- **Кастомизированный дизайн:** Темы разработаны с нуля на основе макета из Figma, что обеспечивает уникальный и привлекательный внешний вид.

- **Гибкие страницы контента:** Использование ACF Flexible Content для создания динамических блоков на главных страницах, таких как:
  - **Главная (Home)**
  - **О нас (About)**
  
- **Интуитивно понятный магазин:** 
  - Кастомный тип товаров для отображения внешних продуктов на странице **Магазин (Shop)**.
  
- **Истории с интерактивностью:**
  - AJAX-фильтрация и функция "Загрузить еще" на странице **Истории (Stories)**.

- **Удобная связь:**
  - Интеграция Contact Form 7 на странице **Контакты (Contact)** для обратной связи с пользователями.

- **Инстаграм интеграция:**
  - Автоматический вывод постов из Instagram на странице **Инстаграм (Instagram)**.

- **Дополнительные страницы:** 
  - About, The Splendor Collective, SC Portal, Social Landing, Privacy Policy.

## WooCommerce и премиум функционал

- **Адаптация WooCommerce:**
  - Настройка страницы товара (Single Product) для WooCommerce Subscriptions, соответствующей дизайну и функционалу.
  - Возможность загрузки пользовательских аватаров в личном кабинете.

- **Оплата и управление заказами:**
  - Интеграция Stripe Payment для безопасных транзакций.

- **Премиум статьи:**
  - Проверка подписки пользователя и ограничение доступа к премиум контенту.
  - Создание ACF Gutenberg Blocks для удобного редактирования страниц Single Post.
  - Разработка попапов для улучшения пользовательского опыта.

- **Интеграция с Mailchimp:**
  - Сбор данных о подписчиках с помощью плагина MC4WP: Mailchimp for WordPress.

## Используемые плагины

- **Advanced Custom Fields PRO**
- **WooCommerce**
- **WooCommerce Subscriptions**
- **WooCommerce Stripe Gateway**
- **Members**
- **EmbedSocial** – инструменты для работы с социальными медиа
- **MC4WP: Mailchimp for WordPress**

## Установка и настройка

1. Клонируйте репозиторий на локальную машину.
2. Установите необходимые плагины через WordPress.
3. Импортируйте настройки и контент для запуска сайта.
