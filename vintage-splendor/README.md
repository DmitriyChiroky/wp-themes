# Описание проекта

**Название проекта:** Vintage Splendor

Этот проект представляет собой современный блог, предлагающий пользователям доступ к эксклюзивным платным статьям через систему премиум подписки. 

**Ссылка на сайт:** [www.avintagesplendor.com](http://www.avintagesplendor.com)

## Основные функции

- **Адаптивный дизайн:** Созданный с нуля на основе макета из Figma, интерфейс блога интуитивно понятен и приятен для пользователя.
  
- **Разнообразие страниц:**
  - **Главная (Home)** и **О нас (About):** Использование ACF Flexible Content для создания динамичных и разнообразных блоков.
  - **Магазин (Shop):** Кастомизированный тип товаров для продажи внешних продуктов.
  - **Истории (Stories):** Страница категорий с AJAX-фильтрацией и возможностью "Загрузить еще" для улучшения пользовательского опыта.
  - **Контакты (Contact):** Интеграция Contact Form 7 для легкой связи с нами.
  - **Инстаграм (Instagram):** Автоматический вывод постов из Instagram для поддержания актуальности контента.

- **Кастомизация WooCommerce:**
  - **Страница товара (Single Product):** Полная адаптация страницы продуктов для WooCommerce Subscriptions.
  - **Личный кабинет:** Возможность загружать пользовательские аватары и управлять подпиской.
  - **Оплата и подтверждение заказа:** Интеграция Stripe для безопасных платежей.

- **Функционал:**
  - Проверка подписки пользователя с возможностью просмотра премиум контента.
  - Ограничение доступа к премиум статьям для неподписанных пользователей.
  - Создание ACF Gutenberg Blocks для удобного редактирования контента в редакторе Gutenberg.
  - Разработка попапов для улучшения взаимодействия с пользователем.
  - Интеграция форм Mailchimp для сбора email-адресов и ведения рассылок.

## Используемые плагины

- **Advanced Custom Fields PRO** – для создания кастомных полей и блоков.
- **WooCommerce** – для управления магазином и продажами.
- **WooCommerce Subscriptions** – для обработки подписок.
- **WooCommerce Stripe Gateway** – для безопасной оплаты.
- **Members** – для управления доступом и ролями пользователей.
- **EmbedSocial** – для интеграции социальных медиа.
- **MC4WP: Mailchimp for WordPress** – для управления рассылками.
